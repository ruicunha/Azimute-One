06 / Design principles

Rules that protect clarity

Do

  • Keep the chart as the dominant visual surface.
  • Use dark navy for application chrome and pale blue/sand for the map itself.
  • Make current, stale, invalid, and unavailable data visually distinct.
  • Use large touch targets and clear icon/label combinations.
  • Respect the selected chart engine's standard portrayal rules.

Don't

  • Don't apply the UI palette indiscriminately to chart objects.
  • Don't use colour alone to communicate alarms or target categories.
  • Don't let panels obscure critical chart detail.
  • Don't treat this illustrative chart as real chart data.
  • Don't claim production readiness before target-device testing.
